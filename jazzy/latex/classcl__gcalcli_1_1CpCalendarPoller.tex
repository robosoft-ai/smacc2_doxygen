\doxysubsection{Detailed Description}
Component that polls Google Calendar and parses event data. 

This component periodically fetches the agenda from Google Calendar using gcalcli\textquotesingle{}s TSV output format and parses it into \doxylink{structcl__gcalcli_1_1CalendarEvent}{Calendar\+Event} structures.
