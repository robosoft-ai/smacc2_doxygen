\doxysubsection{Detailed Description}
Component that visualizes April\+Tag detections in RViz. 

This component uses \doxylink{classsmacc2_1_1ISmaccComponent_a9a7d49a43aacd065d6247c952ad2851f}{requires\+Component()} to access the \doxylink{classcl__isaac__apriltag_1_1CpAprilTagTracker}{Cp\+April\+Tag\+Tracker} and queries detected tags for visualization. It publishes Marker\+Array messages showing the aggregated position of recently detected tags.
