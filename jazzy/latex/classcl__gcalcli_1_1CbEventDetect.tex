\doxysubsection{Detailed Description}
Async behavior that waits for a calendar event\textquotesingle{}s start time to arrive. 

This behavior configures a watch pattern on the \doxylink{classcl__gcalcli_1_1CpCalendarEventListener}{Cp\+Calendar\+Event\+Listener} and waits for an event matching the pattern to start. When the event start time arrives (minus minutes\+\_\+before), it posts Ev\+Cb\+Success.
