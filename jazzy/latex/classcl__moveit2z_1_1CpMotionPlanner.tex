\doxysubsection{Detailed Description}
Component for centralized motion planning operations. 

This component wraps all Move\+Group\+Interface planning operations to provide a consistent interface for planning motions. It supports planning to\+:
\begin{DoxyItemize}
\item Cartesian poses
\item Joint configurations
\item Named targets
\item Cartesian paths
\end{DoxyItemize}

Pattern\+: API wrapper component with result types
