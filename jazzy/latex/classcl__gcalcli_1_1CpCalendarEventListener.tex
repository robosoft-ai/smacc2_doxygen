\doxysubsection{Detailed Description}
Component that listens for calendar events and triggers notifications. 

This component subscribes to the \doxylink{classcl__gcalcli_1_1CpCalendarPoller}{Cp\+Calendar\+Poller} and monitors events against configured watch patterns. It triggers events when\+:
\begin{DoxyItemize}
\item An event matching a pattern is detected (\doxylink{structcl__gcalcli_1_1EvCalendarEventDetected}{Ev\+Calendar\+Event\+Detected})
\item A watched event starts (\doxylink{structcl__gcalcli_1_1EvCalendarEventStarted}{Ev\+Calendar\+Event\+Started})
\item A watched event ends (\doxylink{structcl__gcalcli_1_1EvCalendarEventEnded}{Ev\+Calendar\+Event\+Ended})
\end{DoxyItemize}

The component tracks triggered events to prevent duplicate notifications.
