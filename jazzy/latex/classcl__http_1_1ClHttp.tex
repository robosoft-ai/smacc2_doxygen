\doxysubsection{Detailed Description}
HTTP/\+HTTPS client with pure component-\/based architecture. 

This client acts as a minimal orchestrator that creates and configures three specialized components during initialization. All HTTP functionality is delegated to components.

Components created\+:
\begin{DoxyItemize}
\item \doxylink{classcl__http_1_1CpHttpConnectionManager}{Cp\+Http\+Connection\+Manager}\+: Manages io\+\_\+context and worker thread
\item \doxylink{classcl__http_1_1CpHttpSessionManager}{Cp\+Http\+Session\+Manager}\+: Manages SSL context and creates sessions
\item \doxylink{classcl__http_1_1CpHttpRequestExecutor}{Cp\+Http\+Request\+Executor}\+: Executes requests and emits response signals
\end{DoxyItemize}

Behaviors should access \doxylink{classcl__http_1_1CpHttpRequestExecutor}{Cp\+Http\+Request\+Executor} directly via requires\+Component() rather than using the client interface.
