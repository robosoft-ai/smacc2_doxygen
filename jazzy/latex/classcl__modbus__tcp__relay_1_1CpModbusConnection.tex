\doxysubsection{Detailed Description}
Component that manages Modbus TCP connection lifecycle and heartbeat monitoring. 

Responsibilities\+:
\begin{DoxyItemize}
\item Create/destroy modbus\+\_\+t context
\item Manage TCP connection state
\item Periodic heartbeat via ISmacc\+Updatable (reads coil status to verify connectivity)
\item Emit connection state change signals
\item Thread-\/safe connection access via mutex
\end{DoxyItemize}

Configuration is loaded from YAML parameters\+: modbus\+\_\+relay.\+ip\+\_\+address\+: IP address of the relay (default\+: "{}192.\+168.\+1.\+254"{}) modbus\+\_\+relay.\+port\+: Modbus TCP port (default\+: 502) modbus\+\_\+relay.\+slave\+\_\+id\+: Modbus slave ID (default\+: 1) modbus\+\_\+relay.\+heartbeat\+\_\+interval\+\_\+ms\+: Heartbeat check interval (default\+: 1000) modbus\+\_\+relay.\+connect\+\_\+on\+\_\+init\+: Connect automatically on init (default\+: true)
