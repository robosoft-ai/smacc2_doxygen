\doxysubsection{Detailed Description}
Component that manages gcalcli connection health. 

This component monitors the connection to Google Calendar via gcalcli. It performs periodic heartbeat checks using "{}gcalcli list"{} and tracks consecutive failures. After max\+\_\+consecutive\+\_\+failures, it emits \doxylink{structcl__gcalcli_1_1EvConnectionLost}{Ev\+Connection\+Lost} events.

The component uses Cp\+Subprocess\+Executor from \doxylink{namespacesmacc2}{smacc2} core for command execution.
