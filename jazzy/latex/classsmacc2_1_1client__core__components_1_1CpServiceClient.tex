Generic ROS2 service client component for SMACC2. 

\doxylink{classsmacc2_1_1client__core__components_1_1CpServiceClient}{Cp\+Service\+Client} provides a reusable service client component that can be used by any SMACC2 client library requiring ROS2 service communication. It follows the same pattern as \doxylink{classsmacc2_1_1client__core__components_1_1CpActionClient}{Cp\+Action\+Client}, providing signals, event posting, and thread-\/safe service call management.

Key Features\+:
\begin{DoxyItemize}
\item Template-\/based for type safety with any ROS2 service type
\item SMACC2 signal integration for event-\/driven responses
\item Automatic SMACC2 event posting via template configuration
\item Both synchronous and asynchronous service call support
\item Thread-\/safe service call execution
\item Service availability checking and waiting
\end{DoxyItemize}
