\doxysubsection{Detailed Description}
Component for visualizing trajectories as RViz markers. 

This component publishes trajectory paths as visualization markers that can be viewed in RViz. It follows the ISmacc\+Updatable pattern for periodic publishing.

Pattern\+: Publisher + ISmacc\+Updatable (similar to nav2z\+\_\+client\textquotesingle{}s Cp\+Waypoints\+Visualizer)
