\doxysubsection{Detailed Description}
Component that tracks April\+Tag detections and transforms them to a target frame. 

This component uses \doxylink{classsmacc2_1_1ISmaccComponent_a9a7d49a43aacd065d6247c952ad2851f}{requires\+Component()} to get the Cp\+Topic\+Subscriber and hooks into its on\+Message\+Received signal. It handles TF lookups to transform tag detections to the target frame (default\+: "{}map"{}) and provides time-\/filtered queries.
