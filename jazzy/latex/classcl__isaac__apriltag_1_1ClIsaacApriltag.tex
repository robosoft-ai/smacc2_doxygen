\doxysubsection{Detailed Description}
Client for Isaac ROS April\+Tag detection. 

This client follows the pure component-\/based architecture pattern. It acts as an orchestrator that creates and wires components\+:


\begin{DoxyItemize}
\item Cp\+Topic\+Subscriber$<$\+April\+Tag\+Detection\+Array$>$\+: Subscribes to /tag\+\_\+detections
\item \doxylink{classcl__isaac__apriltag_1_1CpAprilTagTracker}{Cp\+April\+Tag\+Tracker}\+: Transforms detections to map frame, stores poses
\item \doxylink{classcl__isaac__apriltag_1_1CpAprilTagMissionState}{Cp\+April\+Tag\+Mission\+State}\+: Manages visited/selected tag state
\end{DoxyItemize}

Client behaviors should use requires\+Component() to access tracker and mission state, not direct client fields.
