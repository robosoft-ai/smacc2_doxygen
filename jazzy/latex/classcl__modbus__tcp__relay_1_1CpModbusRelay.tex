\doxysubsection{Detailed Description}
Component that handles Modbus coil read/write operations for 8-\/channel relay. 

Responsibilities\+:
\begin{DoxyItemize}
\item Write single coil (channel on/off)
\item Write all coils simultaneously
\item Read single coil status
\item Read all coil statuses
\item Emit operation result signals
\end{DoxyItemize}

Channel numbering\+: 1-\/8 (user-\/friendly) Coil addresses\+: 0x0000-\/0x0007 (0-\/indexed internally)
