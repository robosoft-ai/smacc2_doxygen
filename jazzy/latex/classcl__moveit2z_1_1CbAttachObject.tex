\doxysubsection{Detailed Description}
Client behavior that attaches a collision object to the robot gripper. 

This behavior attaches a previously created grasping object to the robot\textquotesingle{}s end effector. The object must exist in the \doxylink{classcl__moveit2z_1_1CpGraspingComponent}{Cp\+Grasping\+Component}\textquotesingle{}s grasping\+Objects map. Upon successful attachment, the object is added to the planning scene and attached to the gripper using the finger tip links.
