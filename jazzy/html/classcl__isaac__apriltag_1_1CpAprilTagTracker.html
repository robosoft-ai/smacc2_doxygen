Detailed Description

Component that tracks AprilTag detections and transforms them to a target frame.

This component uses requiresComponent() to get the CpTopicSubscriber and hooks into its onMessageReceived signal. It handles TF lookups to transform tag detections to the target frame (default: "map") and provides time-filtered queries.
