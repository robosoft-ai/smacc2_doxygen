61// Publishes the PX4 state estimate as a ROS TF tree: map -> base_link from
62// /fmu/out/vehicle_attitude (rotation) and CpVehicleLocalPosition (translation),
63// converted from PX4's NED / FRD conventions to ROS ENU / FLU, plus a
64// translation-only map -> base_link_follow and a static base_link -> sensor
65// frame. Optionally also publishes the flown trail as a nav_msgs/Path. `map` is the FMU's local NED origin (ref_lat / ref_lon), expressed
66// ENU: x east, y north, z up. EKF origin resets are not compensated.
67//
68// Opt-in: not created by ClPx4Mr; an orthogonal that wants TF adds it with
69// createClient<ClPx4Mr>()->createComponent<CpTfBroadcaster>(params);
70// Threading: onAttitude runs on the ROS executor and touches no state machine
71// APIs.
