Detailed Description

Client for Isaac ROS AprilTag detection.

This client follows the pure component-based architecture pattern. It acts as an orchestrator that creates and wires components:

  • CpTopicSubscriber<AprilTagDetectionArray>: Subscribes to /tag_detections
  • CpAprilTagTracker: Transforms detections to map frame, stores poses
  • CpAprilTagMissionState: Manages visited/selected tag state

Client behaviors should use requiresComponent() to access tracker and mission state, not direct client fields.
