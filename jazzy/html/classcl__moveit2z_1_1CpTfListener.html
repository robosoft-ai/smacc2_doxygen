Detailed Description

Component for shared TF2 transform management across all behaviors.

This component provides centralized access to TF2 transforms: all instances in a process share one tf2_ros::Buffer and one tf2_ros::TransformListener, owned by the instances themselves (process-wide weak references), so the pair lives exactly as long as some CpTfListener does and is destroyed before the rclcpp context.

Pattern: Static resource sharing (similar to nav2z_client's Pose component)

Take, or create, the shared TF2 buffer and listener.

The first instance creates the tf2_ros::Buffer and tf2_ros::TransformListener; later instances created while one is alive share them. Each instance holds its own strong reference.

Reimplemented from smacc2::ISmaccComponent.
