\doxysubsection{Detailed Description}
Component for centralized trajectory execution. 

This component provides a unified interface for executing trajectories with\+:
\begin{DoxyItemize}
\item Automatic recording to \doxylink{classcl__moveit2z_1_1CpTrajectoryHistory}{Cp\+Trajectory\+History}
\item Consistent error handling and event posting
\item Execution options (velocity/acceleration scaling)
\item Execution time tracking
\end{DoxyItemize}

Pattern\+: Executor with signals (like action clients)
